## 按子系统交叉复核

- `state/`、设置与书签编辑：沿草稿替换/字段修改/增删/重排/保存/导出核对；DOM 行 ID 用于定位，不再从 DOM 收集字段。`bookmarksChanged` 保护未修改的本地化文字，`customText` 保留导入文字，`origUrl` 判断图标应否随 URL 更新，均有独立消费者。
- 书签与搜索：核对 `bookmarks.js`、`category-catalog.js`、`bookmark-search.js`、`search.js`、`events.js`；URL 身份、语言目的地址、网络响应与候选节点复用的职责分别保留。搜索选中索引用于键盘，选中节点引用用于最小化 DOM 写入；原查询用于退回输入，不能由选中词替代。
- 壁纸、主题与 IDB：核对预览/上传/取消/提交/首帧恢复以及图片解码；选择序号阻止迟到结果，提交队列保证存储顺序，最近解码图片避免重新解码。旧 IDB 镜像在下一次实际提交或迁移时删除，未额外增加启动扫描或清库任务。
- 天气、时钟与语言：核对首帧脚本、网络转换、地点及天气缓存、刷新任务、日期/描述生成、语言取消/保存。旧气象文字无法反推出天气代码，保留兼容显示；数字和时间安全处理继续保留。
- 其余 `core/`、初始化与全局事件：核对切屏、滚轮/触屏、拖拽、倾斜、浮层、对话框、生命周期、唤醒和更新通知。`editOpen` 在等待壁纸读取时已为真、浮层尚未入栈，不能简单从栈派生。浮层原始 inert 状态用于恢复，当前屏与过渡锁区分目标和未完成动画。初始化守卫防止重复绑定，不删。
- `sw.js`：安装、校验、修补、waiting/用户确认更新、scope 隔离、上一版图片回退、历史池归属及并发下载合并都有独立生命周期；不删除仍承担旧用户恢复的兼容路径。
- 工具、根配置与 `.github/`：核对构建和共享注入、扩展外置脚本、开发服务/监听、lint、图标同步、截图、W3C、测试运行器/CDP，以及 package 命令、类型配置、托管配置、启动脚本和工作流。未发现可整块删除的工具入口；输入/路径/插槽检查仍属于边界校验。生产构建继续裁除测试桥接。
- HTML/CSS/SVG、JSON、本地资源与文档：核对动态类和图标引用、首帧注入及扩展/PWA 差异。本轮未确认可删除的静态资源或业务模块；README、贡献指南的中英文命令契约一致，无须改写。
