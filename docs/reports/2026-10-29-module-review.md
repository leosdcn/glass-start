# Glass Start 逐模块评估与修复记录

日期：2026-10-29。评估基准为 v5.4.0 / Git `fda6268`；当前修复尚在工作区，版本号未变。

**结论：整体架构合理，保留现有分层。F1–F6 已修复并验证，无须引入框架、事件总线或新的状态管理层。**

评估覆盖全部 43 个 JavaScript 模块及 HTML、样式、数据、Service Worker、扩展、构建、测试和 CI。依据是职责、依赖、状态所有权与真实行为，文件长度不单独作为拆分理由。构建图无静态循环依赖，生产包不包含测试适配层。

## 问题、证据与修复

下表记录基准版本的问题及当前修复。F1–F5 已在生产构建通过真实控件复现；复现时仅控制网络或 IDB 完成时机，没有直接修改应用状态。

| 项目 | 确认的故障 | 当前修复及回归 |
| :--- | :--- | :--- |
| F1 · 取消后仍保存壁纸 | 直链 PNG 在取消后才加载完成，会写入 IDB；加载先完成再取消则不写入，结果依赖时机。 | 复用已有选择序号终止待完成任务，发起时确定草稿语义。生产慢 PNG 下载完成后不显示或保存；上传读取/处理取消也已覆盖。 |
| F2 · 旧保存关闭新窗口 | 在壁纸提交读取期间取消重开，放行旧任务会关闭新设置窗口。可能误保存新语言并刷新是源码推断，非直接实测后果。 | IDB 读取后与提交返回后验证原会话；低层提交不再修改弹窗快照。旧任务不开始失效写入，也不修改新草稿、快照或窗口。 |
| F3 · URL 参数改写 | 导入 `?a=1&b=2`，改名保存后真实参数变为 `a=1`、`amp;b=2`。 | 原生 DOM 属性使用协议校验后的原始 URL，HTML 模板仍转义；节点复用、多参数链接及不安全协议回归通过。 |
| F4 · 同查询重复请求 | 在途 Bing 查询追加尾随空格，产生两个相同 query 请求。结果已经进入缓存时不能推断为重复联网。 | 输入调度与请求执行统一语言、引擎、规范化查询键；同值复用、真实变化取消及迟到响应隔离回归通过。 |
| F5 · 清缓存影响其他部署 | 真实清理入口删除同源其他 scope 的注册和缓存；不影响其他域名。 | 限定当前 scope；保留其他注册、其他缓存、未知归属历史池和网页共享图标池。扩展清理自己的图标池；离线重载及已存数据保留通过。 |
| F6 · 测试与保存契约冲突 | 动画测试 mock 缺少 8 个导出；壁纸测试与 README 均要求即选即存，但实现为设置内草稿。不能仅凭实现认定测试过时。 | 用户授权后沿用设置内预览、完成保存、取消放弃，弹窗外快捷键立即保存；统一文档和断言。补齐 mock，保留实际提交时的事务失败与重试验证。 |

位置：[壁纸](../../src/js/modules/wallpaper.js)、[设置](../../src/js/modules/settings.js)、[URL 渲染](../../src/js/modules/bookmarks.js)、[URL 过滤](../../src/js/utils/helpers.js)、[搜索](../../src/js/modules/search.js)、[缓存清理](../../src/js/modules/settings-events.js)。

同一壁纸流程还修复了预设快照歧义：原来 `null` 同时表示任意预设和“恢复默认”，会漏保存或回退。现在快照保存具体预设路径，草稿 `null` 仅表示恢复默认；预览、选中态、取消和保存已验证。

设置仍按字段顺序保存，不提供跨 LocalStorage 和 IDB 的整体原子事务；已经开始或完成的写事务不提供事后撤销。F2 的会话检查负责阻止过期任务继续写入或干扰新窗口。

## 逐模块结论


以下覆盖全部 43 个 JS 模块及其他工程模块。“保留”表示职责与规模匹配，不代表穷尽所有输入和环境；F1–F6 均已在本次工作区修复。
