# Glass Start — Safari / WebKit 专项冒烟与回归验证清单

本文用于在 **macOS Safari** 与 **iOS Safari (WebKit)** 上手工验证浏览器差异。局部修改只走查受影响的用例；版本发布前走查基础功能、PWA 离线及更新主流程。涉及重大样式、手势或生命周期调整时，扩大到对应专项，验证范围遵循 [AGENTS.md](../AGENTS.md#验证)。

本文是手工走查清单，不依赖 CI 自动化；Safari 自动化冒烟入口已移除，以控制个人项目的维护成本。

---

## 一、为什么需要 WebKit 专项冒烟

Glass Start 深度使用原生 Web API、CSS 硬件合成及物理手势系统。Chromium 与 WebKit 存在以下关键特异性差异：

1. **毛玻璃复合图层 (`backdrop-filter`)**：WebKit 在处理多层嵌套模糊与滚动内容时，曾有滤镜失效或穿透历史。
2. **移动端视口与输入框防缩放**：iOS Safari 对 `font-size < 16px` 的输入框会在获取焦点时强行放大整个视口，破坏双屏固定布局。
3. **BFCache 与 GPU 磁贴重建**：iOS Safari 在后台唤醒或手势侧滑返回时，曾出现 GPU 磁贴冻结导致的“白屏”，本项目通过 `pageshow` 校准屏幕状态，并在 BFCache 恢复时调整 `willChange` 提示合成层更新；实际外观仍需实机验证。
4. **弹性过滚动与手势串扰**：iOS Safari 的 Rubber-banding 容易与全屏双屏滑屏手势产生竞态。
5. **安全区留白 (`safe-area-inset`)**：iPhone 灵动岛/刘海与底部手势横条需要精准适配，避免内容遮挡。

## 三、专项验证用例

### 1. 首屏渲染与毛玻璃外观

- [ ] **视觉质感**：首屏加载无闪烁，壁纸渐变暗色遮罩正常，搜索框与天气胶囊呈现毛玻璃背景（无锯齿，无白色背景穿透）。
- [ ] **顶栏沉浸色**：Safari 顶部地址栏颜色与当前壁纸采样的主题色 (`meta[name="theme-color"]`) 动态融合。
- [ ] **3D 视差倾斜 (macOS)**：鼠标滑过快捷书签卡片时，卡片呈现顺滑轻微的 3D 角度倾斜，移出时光影平滑复原，无闪烁。
- [ ] **触控长按保护 (iOS)**：在快捷书签上长按，**不会**弹出 Safari 默认文本选择框或链接预览卡片（`-webkit-touch-callout: none`）。

### 2. 搜索框与键盘交互

- [ ] **iOS 防放大**：点击 `#searchInput` 呼起 iOS 虚拟键盘，视口保持 1:1 比例，**页面不发生意外放大或左右偏移**。
- [ ] **搜索联想下拉**：输入拼音或英文（如 `git`），联想菜单平滑展开，文字清晰可读。
- [ ] **键盘方向导航**：在联想列表激活状态下，按键盘方向下键切换高亮项，**不会**误触发向下滑屏至第二屏。
- [ ] **Escape 退栈**：输入查询并用方向键选中联想项，按 `Escape`，联想菜单收起、输入恢复为原查询，焦点保持在搜索框；未选中联想项时保留当前查询。此项以联想菜单位于浮层栈顶为前提，无浮层时按 `Escape` 会使搜索框失焦。
- [ ] **清空输入**：点击清空按钮，查询词变为空、联想菜单收起，焦点回到搜索框。

### 3. 双屏切屏与手势调度

- [ ] **滚轮切屏 (macOS)**：在起始页向下滚动滚轮，页面顺滑推移进入导航页；导航页同一轮滚动到顶部后继续滚动不应返回，停下后重新向上滚动才回退。触控板缓慢连续滚动也可切屏，侧边栏滚动与捏合缩放不应触发切屏。
- [ ] **快速轻扫 (iOS Flick)**：在起始页向上快速滑动手指（满足 `CONFIG.GESTURE` 的轻扫位移及平均速度阈值），平滑推入导航页；在导航页顶部向下轻扫，平滑退回起始页。
- [ ] **BFCache 恢复**：进入导航页，复制一个外部链接地址并在当前标签页地址栏访问，再用 Safari 后退按钮或返回手势回到应用。书签默认新标签打开，直接点击书签后切回不属于此用例。返回后在控制台调用 `window.__GLASS_DIAG__.dump()`，确认本次 `pageshow` 记录的 `d.persisted === true`；未命中或无法取证时记为“未覆盖”。命中后检查导航内容可见、无持续白屏、切屏可操作，回到首屏后时钟继续更新。
- [ ] **新标签页返回后的毛玻璃**：分别从第一屏、第二屏点击书签在新标签页打开，切回原标签页后往返切屏；动画中及结束后第二屏底板持续模糊壁纸，无突然变清晰或闪白。此路径走可见性恢复，须与 BFCache 分开验证；布局和计算样式断言不能替代实际外观检查。
- [ ] **触屏到顶保护**：从内容中间下滑到顶部，同一次滑动不返回首屏；松手后重新下滑才返回，多指缩放和取消后不残留切屏状态。
- [ ] **减弱动效**：系统开启减弱动效后切屏立即完成，可立即用反向输入返回；动画中开启也不会残留锁定。
- [ ] **切屏状态锁**：切屏动画进行过程中，连续快速乱划或敲击按键，动画结束后状态保持一致，不卡死在半屏位置。

### 4. 分类导航与侧边栏联动

- [ ] **移动端水平 Tab (iOS)**：导航页顶部侧边栏呈横向水平滑动，滚动顺畅；点击末尾分类，高亮指示器居中或滚动到可视区。
- [ ] **安全区留白**：iPhone 竖屏与横屏切换时，导航页顶部 Header 与底部内容区均自动避开刘海/灵动岛与 Home 条。
- [ ] **触控目标达标**：侧边栏各分类 Tab 触控区域高 >= 44px，手指点击判定灵敏准确。
- [ ] **内容滚动隔离**：从书签列表中间开始下滑，仅内容区内部滚动；同一次滑动到顶不会接着返回首屏。已在顶部时的新一轮下滑可按手势规则返回。

### 5. 设置弹窗与无障碍焦点锁 (Focus Trap)

- [ ] **弹窗唤起与背景锁定**：点击右下角齿轮按钮唤起设置面板，背景起始页即刻模糊并处于 `inert` 隔离状态，背景内容无法被点击或滚动。
- [ ] **Tab 切换顺畅**：在“快捷书签”、“外观壁纸”、“数据管理”三个 Tab 间切换，对应内容正确显示，无空面板或明显布局跳动。
- [ ] **键盘循环锁定 (macOS)**：按 `Tab` 键向后遍历设置项，到达末尾后再次按 `Tab` 回绕至首个焦点元素；按 `Shift + Tab` 反向回绕至末项。
- [ ] **优雅退栈与焦点归还**：按 `Escape` 键（或点击关闭按钮），弹窗收起，焦点归还给仍有效的触发源（齿轮按钮）。

### 6. PWA 独立模式与离线功能 (iOS)

- [ ] **添加到主屏幕**：通过 Safari 分享面板选择“添加到主屏幕”，桌面图标完整（由 Apple Touch Icon 正确生成，无黑边或缺损）。
- [ ] **独立视口打开**：从桌面图标启动 Glass Start，无 Safari 浏览器顶栏和底栏（完整全屏应用体验）。

离线准备：通过 HTTPS 访问，在待测运行方式内保持联网，等待 Service Worker 安装并激活，再重新加载，确认 `navigator.serviceWorker.controller` 非空。联网加载待测壁纸与书签图标；涉及导航图标时先进入导航页并滚动到待测区域。天气需先成功获取一次。仅开启飞行模式可能仍有 Wi-Fi，需确认网络已实际断开。

- [ ] **离线页面与本地资源**：断网后重新加载，页面外壳、时钟和书签列表可用，已缓存的壁纸与图标显示正常。安装只预缓存核心页面、脚本及首张预设壁纸；其他图片按请求缓存，不要求未缓存图片或跨域壁纸离线可用。
- [ ] **天气与网络功能降级**：已有有效天气缓存时显示缓存数据，不要求更新为实时天气；无有效缓存时允许显示“暂无数据”及错误提示。网络联想不可用时仍可使用本地书签匹配；外部网站访问需要网络。无缓存场景可在独立测试配置中验证，不清除日常数据。

### 7. 版本更新

在可控测试站点上，先打开旧版并确认页面受 Service Worker 控制，再在同一地址部署新版。发布前或修改更新机制时验证以下主流程，无需因普通文案、样式修改重复执行：

- [ ] **新版提示与稍后更新**：新版下载完成后显示“有新版本”，页面不会自行刷新；打开确认框选择“稍后再说”，仍可继续使用旧页面。
- [ ] **确认更新**：确认“立即更新”后页面刷新并加载新版；已保存的书签与偏好保留。设置弹窗打开时，背景更新按钮不可交互，未保存草稿不被后台更新打断。
- [ ] **多标签页**：让两个标签页保持旧版，其中一个确认更新后刷新，另一个只显示提示、保留当前页面；另一个自行确认后才刷新。

以下异常流程在修改更新机制或排查相关故障时补测，不纳入 5 分钟快速冒烟：

- [ ] **超时与重试**：在隔离测试环境中使待激活 worker 无法完成激活（例如用调试器暂停其 `ACTIVATE_UPDATE` 消息处理），等待 `CONFIG.TIMERS.SW_UPDATE_TIMEOUT` 后显示“更新暂未完成，请重试”，按钮恢复可用；解除阻塞后可重新确认更新。页面不应清空缓存、注销 worker 或丢失已保存设置。仅断网未必能使已下载的新版激活超时；无法构造时记录“未覆盖”。
