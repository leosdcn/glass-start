# Glass Start — Safari / WebKit 验证清单

用于 macOS Safari 与 iOS Safari 的手工验证，不纳入 CI。局部修改只走查受影响项；发布前验证基础功能、PWA 离线与更新主流程。重大样式、手势或生命周期改动需覆盖对应专项，范围见 [AGENTS.md](../AGENTS.md#验证)。

## 一、验证重点

Chromium 测试不能替代 WebKit 实测，重点检查：

- `backdrop-filter` 在嵌套、滚动和切屏时的显示。
- 输入框聚焦时的视口缩放与位移。
- BFCache 和后台恢复后的图层、内容及交互。
- 弹性滚动与切屏手势的冲突。
- 刘海、灵动岛和底部手势条的安全区留白。

## 二、测试环境与记录

| 平台 | 设备 | 重点 |
| :--- | :--- | :--- |
| macOS Safari | MacBook（Retina 屏） | 鼠标倾斜效果、滚轮、键盘焦点、地址栏颜色 |
| iOS / iPadOS Safari | 带刘海或灵动岛的 iPhone；有条件时补充 iPad | 触屏、虚拟键盘、安全区、PWA 独立模式 |

每次走查记录一次：

- 日期、应用版本或构建指纹。
- 设备、系统、Safari 版本及运行方式（标签页 / 主屏幕独立模式）。
- 覆盖项、结论（通过 / 失败 / 未覆盖）及异常现象。

缺少设备、缓存或 BFCache 等前提时，记为“未覆盖”并说明原因。

## 三、专项用例

### 1. 首屏与毛玻璃

- [ ] **首屏外观**：壁纸与暗色遮罩正常，搜索框和天气胶囊背景模糊，无闪白或背景穿透。
- [ ] **地址栏颜色**：切换壁纸后，支持取色的 Safari 地址栏随底色与顶栏自适应更新。
- [ ] **3D 倾斜（macOS）**：鼠标移入导航书签时卡片轻微倾斜，移出后复原，无闪烁。
- [ ] **混合输入（iPadOS）**：页面打开后接入鼠标/触控板，浏览器报告支持悬停与精细指针时，无需刷新即可启用导航卡片倾斜；手指操作不触发倾斜，移除鼠标或开启减弱动效后无残留变换。
- [ ] **长按（iOS）**：长按快捷书签，不弹出文本选择框或链接预览（`-webkit-touch-callout: none`）。

### 2. 搜索与键盘

- [ ] **防放大（iOS）**：聚焦 `#searchInput`，键盘弹出后页面不意外放大或横向偏移。
- [ ] **联想展示**：输入 `git` 等关键词，联想列表展开，文字清晰。
- [ ] **方向键**：联想列表展开时，按 `↓` 切换高亮项，不触发切屏。
- [ ] **Escape**：联想菜单位于栈顶时，按 `Escape` 收起菜单并保持搜索框焦点；已选中联想项时恢复原查询，否则保留当前查询。无浮层时，`Escape` 使搜索框失焦。
- [ ] **清空**：点击清空按钮，输入和联想列表清空，焦点回到搜索框。

### 3. 切屏与生命周期

- [ ] **滚轮（macOS）**：首屏向下滚动进入导航页，触控板缓慢滚动也可触发。导航内容滚到顶部后，同一轮滚动不返回；停下后重新向上滚动才返回。侧边栏滚动和捏合缩放不触发切屏。
- [ ] **轻扫（iOS）**：首屏上滑进入导航页，导航页顶部下滑返回；轻扫需满足 `CONFIG.GESTURE` 的位移与平均速度阈值。
- [ ] **BFCache 恢复**：进入导航页，将外部链接复制到当前标签页地址栏并访问，再后退返回。调用 `window.__GLASS_DIAG__.dump()`，确认本次 `pageshow` 记录的 `d.persisted === true`。检查导航内容可见、无持续白屏、切屏可操作，回到首屏后时钟继续更新。未命中或无法取证时记为“未覆盖”。
- [ ] **切回标签页**：分别从首屏、导航页点击书签，再切回原标签并往返切屏。导航页底板在动画中及结束后保持模糊，无突然变清晰或闪白。此项验证可见性恢复；书签默认新标签打开，不属于 BFCache 用例。需实际观察外观，不能仅凭布局或计算样式判定。
- [ ] **触屏到顶保护**：从内容中间下滑到顶部，同一次滑动不返回；松手后重新下滑才返回。多指操作或手势取消后无残留切屏状态。
- [ ] **减弱动效**：开启减弱动效后切屏立即完成，可反向返回；动画中开启也能解除锁定。
- [ ] **切屏锁定**：动画中连续滑动或按键，结束后屏幕状态一致，不停留在半屏。

### 4. 分类导航

- [ ] **窄屏分类栏**：分类横向滚动正常；点击末尾分类后，所选项进入可视区。
- [ ] **安全区**：iPhone 横竖屏下，导航页顶栏和底部内容不被刘海、灵动岛或手势条遮挡。
- [ ] **触控区域**：分类项高度 >= 44px，点击响应正常。
- [ ] **滚动隔离**：从书签列表中间下滑，仅内容区滚动，同一次滑动到顶不返回首屏；顶部新一轮下滑可返回。

### 5. 设置与焦点

- [ ] **背景隔离**：打开设置，背景模糊并通过 `inert` 隔离，无法点击或滚动。
- [ ] **Tab 面板**：切换“快捷书签”“外观壁纸”“数据管理”，内容正确，无空面板或明显布局跳动。
- [ ] **焦点循环（macOS）**：`Tab` 从末项回到首项，`Shift + Tab` 从首项回到末项。
- [ ] **关闭与焦点归还**：按 `Escape` 或点击关闭按钮，面板收起，焦点回到仍有效的触发按钮。

### 6. PWA 与离线（iOS）

- [ ] **添加到主屏幕**：通过 Safari 分享菜单添加，图标完整，无黑边或缺损。
- [ ] **独立模式**：从主屏幕启动，无 Safari 顶栏和底栏。

离线测试前，通过 HTTPS 联网访问，等待 Service Worker 激活后重新加载，确认 `navigator.serviceWorker.controller` 非空。加载待测壁纸和图标；导航图标需进入导航页并滚动到对应区域。天气先成功获取一次。飞行模式下仍需确认 Wi-Fi 等网络已断开。

- [ ] **离线资源**：断网重载后，页面、时钟和书签列表可用，已缓存壁纸与图标正常。仅核心页面、脚本和首张预设壁纸在安装时预缓存；不要求未缓存图片或跨域壁纸离线可用。
- [ ] **降级显示**：有有效天气缓存时显示缓存，无有效缓存时允许显示“暂无数据”及错误提示。本地书签匹配可用，网络联想和外部网站需要网络。无缓存场景用独立测试配置验证，避免清除日常数据。

### 7. 版本更新

在测试站点打开受 Service Worker 控制的旧版，再在同一地址部署新版。发布前或修改更新机制时验证：

- [ ] **提示与推迟**：新版下载完成后显示“有新版本”，不自动刷新；选择“稍后再说”可继续使用旧页面。
- [ ] **确认更新**：确认“立即更新”后刷新至新版，保留已保存书签与偏好。设置弹窗打开时，背景更新按钮不可交互，后台更新不打断未保存草稿。
- [ ] **多标签页**：两个旧版标签中，一个确认更新后刷新，另一个保留当前页面并显示提示，自行确认后才刷新。

修改更新机制或排查故障时，再补测以下异常流程：

- [ ] **超时重试**：在隔离环境暂停 worker 的 `ACTIVATE_UPDATE` 消息处理，阻止激活。等待 `CONFIG.TIMERS.SW_UPDATE_TIMEOUT` 后，应显示“更新暂未完成，请重试”，按钮恢复可用；解除阻塞后可重新确认。缓存、worker 注册和已保存设置应保留。仅断网未必能阻止激活；无法构造时记为“未覆盖”。
