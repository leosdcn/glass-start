# Glass Start - 玻璃拟态个人起始页

基于 HTML5、Tailwind CSS 与 Modern JS 构建的高颜值、轻量级玻璃拟态（Glassmorphism）浏览器起始页。

---

## 📁 项目目录结构与文件作用

以下是项目根目录中各文件的详细职责与依赖关系说明：

| 文件 / 目录名 | 属性 | 文件作用描述 | 必选性 |
| :--- | :--- | :--- | :--- |
| **`index.html`** | **核心文件** | 页面主入口。包含完整的 HTML 结构、UI 渲染逻辑、搜索引擎切换、书签管理及缺省数据回退逻辑。 | **必须** |
| **`style.css`** | **核心样式** | 编译后的静态 Tailwind CSS 样式文件（约 14KB），提供高效稳定的页面样式支持。 | **必须** |
| `input.css` | 构建源码 | Tailwind CSS 的构建入口文件，供后续开发重新编译 `style.css` 时使用。 | 开发必须 |
| **`bookmarks.json`** | 配置文件 | 外部书签与分类数据源。通过 JSON 格式解耦数据与界面，方便快速备份、导入和编辑书签。 | 推荐（缺失时将回退至内置默认数据/本地存储） |
| **`sw.js`** | 缓存脚本 | Service Worker 独立脚本。专门用于在 HTTPS/localhost 环境下拦截并本地缓存 Favicon 网站图标，提高后续加载速度。 | 推荐（缺失时不影响主流程运行） |
| `.gitignore` | 配置文档 | Git 版本控制忽略配置，防止系统临时文件（如 `.DS_Store`）提交到仓库。 | 运维配置 |
| **`README.md`** | 说明文档 | 本文档，记录项目架构、文件职责、运行机制及部署指南。 | 运维文档 |

## ⚙️ 核心运行与依赖机制

### 1. 文件协作流程
```
[ 用户访问 index.html ]
         │
         ├── 1. 尝试读取外部 bookmarks.json (配置解耦)
         │      ├── 成功: 加载外部书签分类数据
         │      └── 失败/缺失: 自动回退使用内置默认数据及 localStorage
         │
         └── 2. 尝试注册 Service Worker (sw.js)
                ├── 成功: 开启 Favicon 图标本地二级缓存 (CacheStorage)
                └── 失败/缺失/file:// 协议: 静默忽略，使用普通浏览器 HTTP 缓存
```

### 2. 多环境运行兼容性
* **单文件运行（`file://` 本地直接双击打开）**：
  只需要 `index.html` 一个文件即可正常起效。即使没有 `bookmarks.json` 或 `sw.js`，页面也能靠内置回退数据和浏览器标准缓存良好运行。
* **服务器 / HTTPS / localhost 部署**：
  保留 `index.html` + `bookmarks.json` + `sw.js` 完整三件套，可获得最流畅的图标缓存与离线体验。

## 🚀 部署与使用方式

1. **直接本地打开**：
   双击 `index.html` 即可在浏览器中体验。

2. **静态服务器部署**：
   将根目录文件上传至 GitHub Pages、Cloudflare Pages、Vercel 或 NAS 静态 Web 服务中，即可在多端同步使用。

---

## 🛠️ 自定义配置

* **修改书签**：可直接修改 `bookmarks.json` 文件结构（支持 `"desc"` 简短介绍副标题，**推荐控制在 6 ~ 10 个中文字符**），或者在页面 UI 中的编辑模式下进行修改（数据会自动保存在浏览器的 `localStorage` 中）。
* **修改引擎**：可在 `index.html` 中的搜索引擎配置数组中新增或定制新的搜索引擎（百度、Google、Bing 等）。
